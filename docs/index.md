## What is Supersede Studio?

Supersede Studio is a database manager and SQL GUI. It is a desktop app that is easy to use. It's a visual alternative to command line tools like `psql` or `mysql`, while also providing a bunch of useful extra features.

### Platforms Supported by Supersede Studio

Supersede Studio is available for laptops and desktops running [MacOS](./installation/macos-m1-intel.md), [Windows](./installation/windows.md), and [Linux](./installation/linux.md).

Importantly, Supersede Studio offers **full feature parity** across all supported operating systems.

Unfortunately we do not currently have any plans to port Supersede Studio to iOS or Android devices.

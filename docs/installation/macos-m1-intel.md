## Download From Our Website
To install Supersede Studio download the `dmg` installer file from [our website](https://supersedestudio.io), then drag the Supersede Studio application into your application drawer.

Note that by default MacOS will prevent you from installing third-party distributed apps (through the Mac app store). To enable this, navigate to `Settings -> Security and Privacy`, and enable `App Store and Identified Developers`:

## Apple Silicon vs Intel

Supersede Studio installers are available for both Intel and Apple silicon Macs. You can choose your preferred installer type when downloading from the website.


### Choose Your Architecture
When downloading Supersede Studio, be sure to choose the version that matches your MacOS architecture.

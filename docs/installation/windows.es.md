## Simplemente descarga y ejecuta


Descarga y ejecuta el instalador de Windows desde [nuestro sitio web](https://supersedestudio.io).

Actualmente Supersede Studio solo es compatible con la arquitectura `x86_64`. El soporte para `ARM64` llegara en una version futura.


## Version portatil de Supersede Studio

Tambien tenemos una version portatil de Supersede Studio que no requiere instalacion. Esta tambien esta disponible en nuestro sitio web.
